# Math Practice and Speed Drills
Route: /da-montou-games/#math

This is the home screen for two related practice and speed drill games.

The beginning screen shows a title “Math Mantou” centered on the screen in 25 pt font.
Below the title is a set of toggle options.
Below toggle options is a main menu.
The background is dark grey.
Text is color #f0f0f0.
Options / button background is light purple.

The toggle options are a set of operations, presented horizontally:
- Add
- Subtract
- Multiply
- Divide
Tapping on each of these selects or unselects them. When not selected, they are the default background color of light purple. When selected, the background is faded orange.
The set of selected options here is the “active operations” referred to elsewhere.
No visible checkboxes.

The main menu has these items, presented horizontally:
- Practice
- Speed Drill
Tapping on one of these takes the user to the chosen game.
